# Third-party notices and intellectual lineage

## Ideas (no code copied)

TraceForge's design is *inspired by* published research. No source code from these works is
included; credit is for ideas only, and nothing here claims novelty over them.

* **BUSTLE: Bottom-Up Program Synthesis Through Learning-Guided Exploration** (Odena et al., ICLR 2021) —
  learned scoring of intermediate values to prioritise bottom-up enumeration over string
  transformations. TraceForge's integer cost bands (`base + ⌊λ(1−p)⌋`) follow this idea; the
  features, model, DSL and scheduling-invariant proof here are independent re-implementations.
* **CrossBeam: Learning to Search in Bottom-Up Program Synthesis** (Shi et al., ICLR 2022) —
  motivation for learning-guided bottom-up search and for evaluating compositional generalisation.
  TraceForge does *not* implement CrossBeam's beam search or its neural architecture.
* **FlashFill / programming by example** (Gulwani, POPL 2011) and the SyGuS competition string
  benchmarks — the problem setting. No benchmark files are redistributed here; the optional SyGuS
  importer described in the spec was not implemented in this build.
* **Semantic deduplication of observationally-equivalent programs** is classical in bottom-up
  enumeration (e.g. Udupa et al., Transit, PLDI 2013; Albarghouthi et al., Escher, CAV 2013).

## Data

All training and evaluation data are generated by this repository's code from synthetic word
lists (`data/families.py`) and 40 hand-written tasks (`data/authored.py`). Names in examples are
generic/fictional or public historical figures used only as sample strings; no personal data and
no third-party datasets are included.
